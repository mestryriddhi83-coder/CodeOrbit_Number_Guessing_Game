# Number Guessing Game

## Project Title

Number Guessing Game

## Description

A simple command-line Number Guessing Game developed using Python as part of the CodeOrbit Tech Python Programming Internship – Task 3.

The application randomly selects a number between 1 and 100, and the user tries to guess the number. The game provides hints such as "Too high" or "Too low" after each guess and tracks the number of attempts taken.

## Features

- Generates a random number
- Allows the user to guess the number
- Provides "Too high" and "Too low" hints
- Tracks the number of attempts
- Allows multiple rounds of the game
- Handles invalid inputs
- Simple command-line interface

## Technologies Used

- Python 3.14.7
- VS Code
- Random module

## How to Run

1. Make sure Python is installed on your system.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python number_guessing_game.py

5. Enter your guesses and follow the hints provided by the game.
6. Choose `yes` to play another round or `no` to exit.

## Example

🎯 Welcome to Number Guessing Game!

I have selected a number between 1 and 100.
Try to guess it!

Enter your guess: 50
Too high! Try again.

Enter your guess: 25
Too low! Try again.

Enter your guess: 37
🎉 Correct! You guessed the number in 3 attempts.

Do you want to play again? (yes/no): no

Thanks for playing! 👋
